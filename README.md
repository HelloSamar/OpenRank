# PYQxBot — Daily Quiz Product for Competitive Exams

One-line pitch
--------------
PYQxBot helps millions of exam aspirants build speed, accuracy, and confidence with micro‑quizzes (15s) across English, Reasoning, Quant, GK and Current Affairs — scalable, social, and habit‑forming.

The problem
-----------
- Millions of students preparing for SSC, Railway, Banking and state exams struggle with consistency, time-pressure, and retention.
- Existing solutions are long, unfocused, or require heavy onboarding — students skip them.
- Coaching centers need lightweight tools to run live drills and measure class readiness.

Our solution
------------
PYQxBot is a product‑grade, daily quiz engine that turns 5–10 minutes of daily practice into measurable improvement:
- 15‑second timed MCQs that replicate exam pressure.
- Instant per‑question feedback and per‑quiz analytics.
- Group/Channel mode for live rounds, leaderboards, and classroom engagement.
- Lightweight UX — no friction, high retention.

Why now
--------
- Large, growing market of competitive‑exam aspirants across India and similar markets.
- Mobile-first consumption habits favor quick, habitable learning formats.
- Coaching centers and groups are actively looking for scalable digital engagement tools.

Product & key features
----------------------
- Speed-first format: default 15s timer for each question to train fast decision-making.
- Exam-calibrated scoring: +2 / -0.5 to mirror real test scoring and teach risk control.
- Per-quiz analytics: score breakdown, accuracy, time per question, and streaks.
- Social & competitive mechanics: leaderboards, streaks, badges, and group challenges.
- Lightweight entry: no mandatory signup; opt-in tracking for power users and groups.
- Extensible: API / content packs for coaching partners and custom branded quizzes.
